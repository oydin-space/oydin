Delivery

POST with a JSON body:

{"id": "5b1c…", "event": "transaction.created",
 "created_at": "2026-11-18T09:30:00+00:00", "data": { ... }}
HeaderValue
X-Oydin-EventEvent name.
X-Oydin-DeliveryUnique delivery id; use it to deduplicate.
X-Oydin-TimestampUnix seconds.
X-Oydin-Signaturesha256= + HMAC-SHA256 hex.

Verify the signature

The signed string is timestamp + "." + raw_body, the key is the endpoint secret shown at creation.

import hmac, hashlib

def verify(secret, timestamp, raw_body, header):
    mac = hmac.new(secret.encode(), f"{timestamp}.".encode() + raw_body, hashlib.sha256)
    return hmac.compare_digest("sha256=" + mac.hexdigest(), header)

Reject deliveries whose timestamp is older than a few minutes.

Retries and limits

  • Answer with any 2xx within 5 seconds.
  • Failed deliveries are retried after 1 minute, 10 minutes and 1 hour.
  • Redirects are not followed.
  • URLs must be https and resolve to public addresses; private and local hosts are rejected.
