Oydin for developers

Read your business data, push transactions, get webhooks, and give the Oydin AI agent your own tools.

Public APIBearer-token REST API under /api/v1/. WebhooksSigned events when transactions change. REST handlerDescribe one HTTP call; the agent can use it. MCP serverConnect a streamable-HTTP MCP server.

Five-minute start

  1. Create a token. In Oydin open Settings → For developers → Tokens, pick read (and write if you need to create transactions). The secret is shown once.
  2. Call the API. 
    curl https://oydin.sayfi.uz/api/v1/pulse/ \
  -H "Authorization: Bearer oyd_XXXXXXXX"
  3. Subscribe to events. Add an https webhook URL and verify X-Oydin-Signature (details).
  4. Extend the agent. Add a REST handler or an MCP server under Settings → For developers → Connectors. Press Test, then ask the AI chat to use it.
Base URL: https://oydin.sayfi.uz/api. All errors are JSON: {"error": "code"}.
Only the business owner can manage tokens, webhooks and connectors.
