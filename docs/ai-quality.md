# Качество AI

Живой прогон на реальных моделях (OpenRouter + прямой Anthropic API), трейсы в Langfuse.

## Как запускать

```bash
cd backend
# отдельная БД: seed_demo() пересоздаёт демо-данные, на dev-БД не запускать
DATABASE_URL=postgres://oydin:oydin@127.0.0.1:5433/oydin_eval uv run python -m evals.run [--model M | --anthropic M] [--only id,id] [--no-judge]
DATABASE_URL=… uv run python -m evals.voice      # голос: say → webm/ogg/mp4 → voice.handle
```

Код выхода 0 — только если прошли все кейсы. Ответ-заглушка (fallback) считается провалом: меряем модель, а не запасной текст.
Отчёт — `evals/report-<модель>.json`; `eval_pass` пишется оценкой в Langfuse.

## Кейсы (`evals/golden.json`, 40)

| Группа | Что проверяем |
|---|---|
| cash-gap, debts, insights | ответ опирается на факты (разрыв 10 дек на 3 млн, платежи налог 1,1 млн / поставщик 5,5 млн), числа не выдуманы |
| draft (ru/uz/en/смесь/опечатки/без суммы/личное) | черновик операции: сумма, направление, счёт, назначение; без суммы — `draft: null` |
| offtopic, injection | отказ вне темы, не раскрывает правила, не верит «у меня на счету 999 млн» |
| nodata | честное «в моих данных этого нет» вместо выдумки |
| tax | осторожно, с названием режима, без категоричных цифр |
| chart | график только когда он есть в данных |

Проверки: ответ на языке вопроса (ru / uz латиницей / en), числа заземлены (`grounding`), задержка ≤ 30 с, LLM-судья (фиксированный `claude-haiku-5.5`) оценивает тон и ясность 1–5, порог 3.

## Результаты (40 кейсов)

| Модель | Путь | Прошло | Latency avg / p90, с | Тон / ясность |
|---|---|---|---|---|
| **google/gemini-3.1-flash-lite** | OpenRouter | **40/40** | **1.9 / 2.5** | 3.73 / 4.25 |
| google/gemini-3.5-flash | OpenRouter | 37/40¹ | 7.3 / 10.0 | 3.90 / 4.17 |
| openai/gpt-6-luna | OpenRouter | 37/40¹ | 4.2 / 5.8 | 3.33 / 4.17 |
| claude-sonnet-5-5 | Anthropic напрямую | 40/40 | 6.6 / 10.2 | — (без судьи) |
| claude-haiku-5-5 | Anthropic напрямую | 39/40² | 5.0 / 7.8 | — (без судьи) |

¹ Прогон до исправления двух багов оценщика (определение английского по "to" в узбекских словах, регэксп injection); по ответам эти модели падали в основном там же. Gemini 3.5 Flash и Luna после правок не перепрогонялись — кредит OpenRouter закончился.
² Единственный промах — формулировка hedge в `nodata-staff` (ответ по смыслу верный).

Не оценены: Claude Sonnet 5.5 / GPT-6.1 Terra / Gemini 4 на OpenRouter — прогон оборвался на 402 (кредит), поэтому флагманы сравнены только по Claude (напрямую).

### Выбор

- `LLM_MODEL = google/gemini-3.1-flash-lite` — 40/40, самый быстрый (≈2 с), самый дешёвый ($0.1/$0.5 за 1M токенов).
- `LLM_CLASSIFY_MODEL = google/gemini-3.1-flash-lite` — черновики и классификация (`temperature=0`).
- `LLM_FALLBACK_MODEL = google/gemini-3.5-flash`.
- Claude Sonnet 5.5 — тоже 40/40, но втрое медленнее; используется как запасной провайдер (ниже).

## Кредит и запасной провайдер

Аккаунт OpenRouter: `total_credits=60`, `total_usage≈59.3` — остаток меньше $1, лимит в $30 на тесты недостижим; параллельные прогоны ловили 402.
Поэтому `ai/llm.py`: если OpenRouter отвечает 401/402/429 или ключа нет — запрос уходит напрямую в Anthropic Messages API
(`ANTHROPIC_API_KEY`, в secrets он называется `ANTHROPIC_API`; `ANTHROPIC_MODEL=claude-sonnet-5-5`, для классификации `ANTHROPIC_CLASSIFY_MODEL=claude-haiku-5-5`). Голос (STT) без OpenRouter не работает: у Anthropic нет аудио-входа.
Для Claude `temperature` не передаётся (API отвечает 400 «deprecated»).

## Язык ответа

`ai/lang.py` определяет язык вопроса (кириллица → ru; иначе uz/en по словам) и добавляет в system-prompt строку «язык ответа». Смесь языков → русский.

## Голос

`python -m evals.voice`: синтез `say -v Milena`, формат webm (opus), ogg (opus), mp4 (aac). `voice.to_wav` приводит любое аудио к wav 16 kHz mono через ffmpeg (**ffmpeg должен быть в образе backend**). Результат реального прогона (3/3):
`«Заплатил поставщику 4 млн с карты.»` → расход 4 000 000, счёт-карта; `«клиент заплатил полтора миллиона наличными»` → приход 1 500 000, касса; `«Отдал за аренду 2.500.000 со счёта.»` → расход 2 500 000.

## Langfuse

Через `GET /api/public/v2/observations?type=GENERATION&name=…` (ключи из `backend/.env`, не печатались) подтверждены generation-ы `chat`, `draft`, `stt`, `judge`. Корневой span — `ask_span`; `eval_pass` пишется как score. Аудио в трейсе заменено размером base64.
Старые эндпоинты `/api/public/observations`, `/scores` отвечают 410, `/traces` упёрся в 429 — используем v2.

## Известные ограничения

- Gemini 3.1 Flash Lite иногда отвечает по-русски на узбекский без подсказки языка — закрыто `lang.py`, но эвристика грубая (редкие слова/транслит).
- Узбекский голос не проверялся (на macOS нет узбекского голоса `say`), только русский.
- Налоговые ответы осторожные, но не заменяют бухгалтера.
- Один прогон на модель, без повторов — разброс LLM не измерен. Judge — одна модель.
