# Integrations: verifiable release boundary

Checked 2026-11-18. Owner decision: only verified integrations are working UI; everything else is **coming soon**. This is web research, not an implementation test report. **SHIP means eligible for implementation and an end-to-end release check, not already working.** No accounts were created, credentials used, payments made, or application tests run.

**Recommendation:** ship CBU and generic CSV/XLSX; ship explicitly scoped 1C/CommerceML **file exchange** after fixture checks. Keep account-dependent connectors coming soon until real authenticated verification. Public documentation, Swagger, a free trial, or a sandbox login page is not anonymous API access. A documented callback simulator is not proof of historical merchant synchronization.

## Release checks owned by implementation

1. **Files:** real upload → mapping/preview → confirmation → tenant-scoped persisted records → pulse update; duplicate reimport must not duplicate cash. Export → independent parser; reconcile original amounts, currencies and balances.
2. **Bank branding:** do not label generic mapping as a verified Kapitalbank/TBC/Uzum/Hamkor preset. TBC screenshots establish export availability, not parser compatibility.
3. **Credentials:** private tokens stay server-side, scoped to the organization, redacted in logs. Real auth expiry, pagination, refunds and reconciliation must be exercised before promoting a connector.
4. **Bot/TTS:** if main agent already has authorized tokens, run real delivery and playback; then update availability. This research did not inspect environment secrets and does not claim they are absent.
5. **UI:** coming-soon card must not offer a functioning-looking connect flow. Logo availability is independent of connector availability; use original colored marks only within verified terms.

Not verified: application behavior; fixture parsing/content and branch-pinned download URLs; account signup/API entitlement; any authenticated vendor request; actual bank export columns; OAuth client; bot delivery; TTS playback and RU/UZ quality; archive contents; brand usage permission where explicitly unresolved. No builds/tests run, as assigned.
